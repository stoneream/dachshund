# dachshund

## 概要

Dachshund は、Spotify でフォローしているアーティストの新着リリースを取得し、確認できるようにするためのシステムである。

新着リリースを確認するためには、Spotify 認可、フォロー中アーティストの取得、アーティストリリースの取得、表示対象となる新着リリースの作成が必要になる。
そのため、Dachshund はユーザー操作を受け取る処理と、表示に必要なデータを裏側で同期する処理を分けている。

## ドキュメント

`docs` 以下の各ディレクトリの役割は次の通り。

- `docs/blog`: 現況の仕様および開発における意思決定を置く。
- `docs/discussion`: 新規機能開発や改修に関する方針、検討中の論点、意思決定前の議論を置く。
- `docs/job`: daemon で実行されるジョブの概要や実行方式を置く。
- `docs/web`: server で公開される Web endpoint の概要を置く。
