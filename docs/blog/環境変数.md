title: 環境変数

## 目的

この文書は、Dachshund の server / daemon を起動するために設定する環境変数を記す。
設定値の正本は `application/src/main/resources/application.conf`、`server/src/main/resources/application.conf`、`daemon/src/main/resources/application.conf` とし、環境変数は `${?ENV_NAME}` 形式で上書きする。

ローカル開発では `mise setup` が `.envrc.example` から `.envrc` を作成する。
`.envrc` には秘密値を含む値を設定するため、コミットしない。

`.envrc.example` の Spotify client ID / secret は、アプリケーションを起動するためのダミー値である。
実際に Spotify OAuth / Web API を使う場合は、Spotify Developer Dashboard で発行した値に置き換える。

## 必須

次の環境変数は、server / daemon の起動または主要機能の実行に必要になる。

| 環境変数 | 用途 | 値 |
| --- | --- | --- |
| `APPLICATION_SECRET` | Play application secret | 32 バイト以上の十分にランダムな文字列 |
| `DACHSHUND_DB_URL` | master DB の JDBC URL | MySQL の JDBC URL |
| `DACHSHUND_DB_USER` | master DB の接続ユーザー | DB ユーザー名 |
| `DACHSHUND_SESSION_SIGNING_KEY_V1` | セッショントークンの署名鍵 | 32 バイトを Base64 エンコードした値 |
| `DACHSHUND_SPOTIFY_CLIENT_ID` | Spotify API / OAuth client ID | Spotify Developer Dashboard で発行した client ID |
| `DACHSHUND_SPOTIFY_CLIENT_SECRET` | Spotify API / OAuth client secret | Spotify Developer Dashboard で発行した client secret |
| `DACHSHUND_SPOTIFY_REDIRECT_URI` | Spotify 認可 callback URL | Spotify 側に登録した redirect URI |
| `DACHSHUND_SPOTIFY_TOKEN_ENCRYPTION_KEY` | 保存する Spotify トークンの暗号化鍵 | 32 バイトを Base64 エンコードした値 |

`APPLICATION_SECRET`、`DACHSHUND_SESSION_SIGNING_KEY_V1`、`DACHSHUND_SPOTIFY_TOKEN_ENCRYPTION_KEY` は秘密値として扱い、ログやドキュメントに実値を書かない。

## DB

| 環境変数 | 用途 | 既定値 |
| --- | --- | --- |
| `DACHSHUND_DB_DRIVER` | DB driver class | `com.mysql.cj.jdbc.Driver` |
| `DACHSHUND_DB_PASSWORD` | master DB の接続パスワード | 未設定 |

`DACHSHUND_DB_PASSWORD` は接続先 DB がパスワードを要求する場合に設定する。

## セッション

| 環境変数 | 用途 | 既定値 |
| --- | --- | --- |
| `DACHSHUND_SESSION_SIGNING_CURRENT_KID` | セッショントークン署名に使う key id | `v1` |

通常は `v1` のまま使う。
key id を変更する場合は、対応する署名鍵も application config に存在する必要がある。

## Cookie

| 環境変数 | 用途 | 既定値 |
| --- | --- | --- |
| `DACHSHUND_COOKIE_SESSION_NAME` | セッション cookie 名 | `dachshund-session` |
| `DACHSHUND_COOKIE_SESSION_SECURE` | セッション cookie の secure 属性 | `false` |
| `DACHSHUND_COOKIE_SESSION_SAME_SITE` | セッション cookie の SameSite 属性 | `lax` |
| `DACHSHUND_COOKIE_SESSION_DOMAIN` | セッション cookie の domain 属性 | 未設定 |
| `DACHSHUND_COOKIE_SESSION_MAX_AGE_SECONDS` | セッション cookie の max age | `2592000` |
| `DACHSHUND_COOKIE_EXTERNAL_AUTH_STATE_NAME` | Spotify 認可 state cookie 名 | `spotify-auth-state` |
| `COOKIE_EXTERNAL_AUTH_STATE_NAME` | Spotify 認可 state cookie 名の旧環境変数 | `spotify-auth-state` |
| `DACHSHUND_COOKIE_EXTERNAL_AUTH_STATE_SECURE` | Spotify 認可 state cookie の secure 属性 | `false` |
| `DACHSHUND_COOKIE_EXTERNAL_AUTH_STATE_SAME_SITE` | Spotify 認可 state cookie の SameSite 属性 | `lax` |
| `DACHSHUND_COOKIE_EXTERNAL_AUTH_STATE_DOMAIN` | Spotify 認可 state cookie の domain 属性 | 未設定 |
| `DACHSHUND_COOKIE_EXTERNAL_AUTH_STATE_MAX_AGE_SECONDS` | Spotify 認可 state cookie の max age | `1800` |

新しく設定する場合は `DACHSHUND_` 接頭辞の環境変数を使う。

## サーバー

| 環境変数 | 用途 | 既定値 |
| --- | --- | --- |
| `APP_ALLOWED_HOST` | Play allowed hosts に追加する host | `localhost`, `.local`, `127.0.0.1`, `dachshund.yap-yap-dog.net` |
| `CORS_ALLOWED_ORIGIN` | CORS allowed origins に追加する origin | `http://127.0.0.1:3000`, `http://localhost:3000`, `https://dachshund.yap-yap-dog.net` |

本番や preview 環境で localhost 以外の host / origin からアクセスする場合に設定する。

## Daemon

daemon の executor 設定は必要な場合だけ上書きする。

| 環境変数 | 用途 | 既定値 |
| --- | --- | --- |
| `DAEMON_DEFAULT_EXECUTOR_THREAD_COUNT` | daemon default executor のスレッド数 | `2` |
| `DAEMON_DEFAULT_EXECUTOR_SHUTDOWN_GRACE_PERIOD` | daemon default executor の停止猶予 | `1s` |
| `DAEMON_DATABASE_EXECUTOR_THREAD_COUNT` | daemon database executor のスレッド数 | `16` |
| `DAEMON_DATABASE_EXECUTOR_SHUTDOWN_GRACE_PERIOD` | daemon database executor の停止猶予 | `1s` |
| `DAEMON_IO_DISPATCHER_THREAD_COUNT` | daemon IO dispatcher のスレッド数 | `16` |
| `DAEMON_IO_DISPATCHER_SHUTDOWN_GRACE_PERIOD` | daemon IO dispatcher の停止猶予 | `1s` |

ジョブの interval、timeout、retry、batch size は環境変数ではなく `daemon/src/main/resources/application.conf` を正本にする。
ジョブごとの `enabled` は `application.conf` で既定値を `true` として明示し、必要な場合だけ環境変数で `false` に上書きする。

| 環境変数 | 用途 | 既定値 |
| --- | --- | --- |
| `DAEMON_JOB_SPOTIFY_ACCESS_TOKEN_REFRESH_ENABLED` | Spotify access token refresh job の有効化 | `true` |
| `DAEMON_JOB_FOLLOWED_ARTISTS_SYNC_QUEUE_ENABLED` | followed artists sync queue job の有効化 | `true` |
| `DAEMON_JOB_FOLLOWED_ARTISTS_SYNC_ENABLED` | followed artists sync job の有効化 | `true` |
| `DAEMON_JOB_ARTIST_RELEASE_SYNC_QUEUE_ENABLED` | artist release sync queue job の有効化 | `true` |
| `DAEMON_JOB_ARTIST_RELEASES_SYNC_ENABLED` | artist releases sync job の有効化 | `true` |
| `DAEMON_JOB_USER_NEW_RELEASE_EVENTS_SYNC_ENABLED` | user new release events sync job の有効化 | `true` |
| `DAEMON_JOB_USER_NEW_RELEASE_NOTIFICATION_DELIVERY_QUEUE_ENABLED` | user new release notification delivery queue job の有効化 | `true` |

`false` にしたジョブは daemon 起動時の scheduler 起動対象から外れる。

## 開発補助

次の値はアプリケーション設定ではなく、ローカル開発用の task や補助ツールで使う。

| 環境変数 | 用途 |
| --- | --- |
| `HOST_UID` | Docker で Flyway / tbls を実行する際の user id。server / daemon の Docker Compose 実行ユーザー上書きにも使う |
| `HOST_GID` | Docker で Flyway / tbls を実行する際の group id。server / daemon の Docker Compose 実行ユーザー上書きにも使う |
| `DOCKER_IMAGE_TAG` | sbt-native-packager で Docker イメージタグを明示する場合に使う。server では CSS / JavaScript の version query にも使う |
| `METALS_MCP_PORT` | Metals MCP サーバーのポート |

`.envrc.example` には `DB_ENABLED` も含まれるが、現時点では server / daemon の `application.conf` からは参照されない。
