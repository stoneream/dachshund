## 目的

この文書は、Dachshund のプロジェクト全体のディレクトリ構造をまとめる。
実装を読むときや変更箇所を決めるときに、どのディレクトリを確認すべきか判断できる状態にする。

モジュールごとの責務や、`usecase`、`step`、`handler`、`renderer` などの実装単位については `docs/blog/アプリケーション構成.md` を参照する。

## 全体像

Dachshund は、Spotify でフォローしているアーティストの新着リリースを取得し、確認できるようにするためのシステムである。

ユーザー操作を受け付ける Web 側の処理と、表示に必要なデータを同期する daemon 側の処理を分けている。
どちらも `application` の UseCase や DB アクセスを利用する。

## 主要ディレクトリ

| ディレクトリ | 役割 |
| --- | --- |
| `application` | アプリケーションの中心となる処理を置く。UseCase、step、DB reader/writer、Spotify 連携、設定などを含む。 |
| `server` | Play Framework による HTTP 入出力を置く。route、controller、handler、renderer、Twirl view などを含む。 |
| `daemon` | バックグラウンドジョブを実行する daemon process を置く。ジョブスケジューラー、ジョブ定義、job handler などを含む。 |
| `logging` | ログ出力の共通基盤を置く。 |
| `codegen` | UseCase、step、server endpoint、daemon、DB アクセサーなどの雛形生成器を置く。 |
| `frontend` | Twirl view に読み込ませる CSS / JavaScript の元ファイルを置く。 |
| `db` | Flyway マイグレーションを置く。 |
| `tbls` | DB スキーマドキュメントを置く。 |
| `docker` | Docker 関連の設定を置く。 |
| `scripts` | 開発や生成処理を補助するスクリプトを置く。 |
| `project` | sbt のプロジェクト設定、依存関係定義、plugin 設定を置く。 |
| `docs` | 仕様、設計判断、開発手順、job 説明などのドキュメントを置く。 |

## frontend の位置づけ

このプロジェクトの `frontend` は、画面全体を持つ SPA ではない。
HTML は `server/src/main/twirl/views` の Twirl テンプレートで生成し、`frontend` は静的に読み込ませる CSS / JavaScript の元ファイルを管理する。

`frontend/src/scss/main.scss` は、`frontend/package.json` の `sass` / `build:sass` によって `server/src/main/public/stylesheets/main.css` に出力される。
`frontend/src/ts/main.ts` は、`frontend/tsconfig.json` の `outDir` 設定に従って `server/src/main/public/javascripts/main.js` に出力される。

`server/src/main/public` に出力されたアセットは、Play Framework の `Assets.versioned` によって HTTP 経由で配信される。
`Assets.versioned` はアセットの配信に使う仕組みであり、CSS / JavaScript を生成する仕組みではない。

## 生成物・ローカル作業領域

`target`、`logs`、`.bloop`、`.metals`、`frontend/node_modules` などは、ビルド、開発ツール、実行時ログによって作られる生成物またはローカル作業領域である。
通常の実装変更では直接編集しない。

`server/src/main/public/stylesheets/main.css` と `server/src/main/public/javascripts/main.js` は `frontend` から生成されるアセットだが、現在は git 管理されている。
ignore 対象の生成物とは扱いが異なるため、変更する場合は `frontend/src` 側を更新し、ビルド結果として `server/src/main/public` 側の差分を確認する。
