## 必須

このリポジトリでは、開発に使うランタイムと CLI の正本を `.mise.toml` に寄せる。

ホスト側で事前に用意するものは、mise と Docker のみとする。
JDK と Node.js も mise で管理する。
Docker は Docker Engine / Docker Desktop と Compose プラグインを使い、コンテナ実行基盤のため mise の管理対象にしない。

## 開発ツールの管理方針

現時点では JDK、Node.js、pnpm、gh、direnv、sbt、Coursier を mise の管理対象とする。

ツールの追加、削除、バージョン更新は `.mise.toml` を正本として行う。
pnpm は `frontend/package.json` の `packageManager`、sbt は `project/build.properties` にもバージョンが出るため、更新時は `.mise.toml` とあわせて変更する。
Coursier は mise の `coursier` レジストリで `github:coursier/coursier` から導入し、CLI は `cs` を使う。
Coursier で入れるプロジェクト用 CLI は `.coursier/bin` に配置し、direnv でこのリポジトリ内だけ `PATH` に追加する。

Flyway と tbls は `.mise.toml` の task 内 Docker イメージタグ、frontend の個別ツールは `frontend/package.json` と `frontend/pnpm-lock.yaml` で管理する。

## 初回セットアップ

mise のインストールは [jdx/mise](https://github.com/jdx/mise) を参照する。
Docker は `docker compose version` が通る状態にしておく。

```bash
# 開発ツールをインストールする
mise install

# ツールチェーンとホスト必須ツールの確認
mise toolchain-check

# 初回セットアップ
mise setup
```

`mise setup` は `.envrc` と `db/flyway.conf` をサンプルから作成し、direnv の許可、Metals MCP のインストール、Codex のプロジェクト限定 MCP 設定生成、frontend 依存のインストール、開発 DB へのマイグレーション適用を行う。
新規作成される `.envrc` では、Coursier が配置する CLI を使えるように `.coursier/bin` を `PATH` に追加する。
アプリケーションで使う環境変数は [環境変数](環境変数.md) を参照する。

個別に実行する場合は以下を使う。

```bash
mise front-install
mise db-up
mise flyway-dev
```

## Codex / Metals MCP

`mise setup` は Metals MCP のインストールと Codex のプロジェクト限定 MCP 設定生成まで行う。
Metals MCP サーバーの起動は行わないため、Codex から利用する場合は Codex セッションを始める前に `mise metals-mcp-start` を実行する。

Codex 設定生成は `mise gen-codex-config` から呼び出す。
Metals MCP の起動 / 停止 / 状態確認処理は、`mise metals-mcp-*` から呼び出す。
デフォルトでは `http://127.0.0.1:39000/mcp` を参照する。
ポートを変える場合は `METALS_MCP_PORT` を設定し、`gen-codex-config` と `metals-mcp-start` を同じ環境変数で実行する。
生成される `.codex/config.toml` は、Metals MCP の診断、モジュール一覧、シンボル検索、ドキュメント / ソース / 使用箇所参照、Scalafix ルール一覧を承認なしで使えるようにする。
`format_file`、`test`、`import_build`、Scalafix rule の生成や実行は自動承認に含めないため、必要な場合は通常の承認フローを使う。
外部ネットワークは有効化しないため、未取得の依存をダウンロードする場合は通常の承認フローを使う。

MCP だけを個別にセットアップする場合は以下を使う。

```bash
mise metals-mcp-install
mise gen-codex-config
```

Codex から Scala の型情報、診断、参照検索を使う場合は、Codex セッションを始める前に Metals MCP サーバーを起動する。
起動ログは `logs/metals-mcp.log` に出力される。

```bash
mise metals-mcp-start
mise metals-mcp-status
```

終了時は以下で停止する。

```bash
mise metals-mcp-stop
```

## 開発

```bash
# バックエンド
mise exec -- sbt

# sbt shell 内
server/run
```

別シェルで frontend の監視ビルドを起動する。

```bash
mise front-watch
```

本番用 frontend アセットは以下で生成する。

```bash
mise front-build
```

## DB スキーマ変更時

DB に変更を加えた場合は、マイグレーションを適用してから `tbls/schema` を更新する。

```bash
mise flyway-dev
mise flyway-test
mise tbls-doc
```

## 検査・整形・テスト

```bash
# フロントエンド
mise front-lint
mise front-format-check

# バックエンド
mise exec -- sbt compile
```

## 開発 DB の停止

```bash
mise db-down

# ボリュームも削除する場合
mise db-down-rm
```
