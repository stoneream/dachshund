## 概要

キューイングされた各アーティストのリリース同期を実行する。

`artist-release-sync-queue` ジョブが作成したキューを取得し、Spotify API からアーティストのリリースを取得する。
何らかの原因により取得に失敗した場合は、失敗内容に応じて再試行できるようにキューの状態を更新する。

## 同期方式

アーティストごとに Spotify のリリース一覧を先頭から最終ページまで走査する。
一覧からはリリース ID と保存に必要な概要だけを取得し、`artist_release` に存在しないリリースだけ詳細と全トラックを追加取得する。
既存リリースの詳細は再取得しない。

## Spotify API のリクエスト制御

このジョブが使用するSpotify Web APIのリクエスト間隔、rate limit、およびバッチ停止時のキュー更新は[Spotify Web APIのリクエスト制御](<../blog/Spotify Web API のリクエスト制御.md>)に従う。

## 補足

認証情報や権限の問題など、再試行しても解消できない失敗は再試行せず、運用対応が必要な状態として扱う。
